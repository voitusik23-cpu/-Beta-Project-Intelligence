# Beta Project Intelligence

Отдельный центр управления разработкой, техническими заданиями, аудитами и приёмкой продукта Beta Project Intelligence.

> Этот репозиторий — control workspace, а не готовая копия приложения. Исходный код и рабочая база приложения остаются в существующей локальной рабочей директории до отдельного решения о переносе.

## Что здесь находится

- PROJECT_RULES.md — обязательные правила безопасной работы.
- MASTER_TASK.md — общее продуктовое и техническое задание.
- WORKLOG.md — подтверждённая история работ и решений.
- tasks/ — очередь заданий для Codex.
- reports/ — отчёты аудита и приёмки.
- docs/ — архитектура, источники и продуктовые решения.

## Текущий приоритет

1. Сохранить существующее приложение, базу и результаты первичного анализа.
2. Довести визуальный стиль до профессионального high-tech уровня.
3. Разобраться, почему найденные проекты/карточки не отображаются на главном экране.
4. Проверить подключение и фактическую работу источников.
5. Продолжать развитие аналитики и мониторинга по MASTER_TASK.md.

## Важное

Не считать задачу выполненной по одному плану или сообщению агента. Нужны изменения в рабочей копии, тесты, проверка UI и конкретные доказательства в отчёте.
