# Beta Project Intelligence

Локальная исследовательская система для поиска и проверки Web3-проектов. Приложение сохраняет исходные публикации, показывает русские описания для рабочей очереди и не считает слухи о финансировании или наградах подтверждёнными фактами.

## Запуск

Дважды щёлкните ярлык **Beta Project Intelligence** или `run.bat`. Ярлык запускает приложение в отдельном окне Google Chrome. Сайты проектов и ссылки из досье также открываются в Chrome, поскольку интерфейс запущен в Chrome.

Приложение и проектная документация находятся в этом репозитории. Локальный запуск выполняется через `run.bat`.

Требования: Windows 10/11, Python 3.12+, интернет для сбора общедоступных источников. API приложения доступен на `/docs`, проверка состояния — `/api/health`.

## Данные и источники

SQLite-файл расположен в `data/beta_intelligence.sqlite3`. Перед расширением схемы создана резервная копия в `data/backups`. Исходные проекты сохраняются; результаты первичного отбора помечают карточки как PASS, REVIEW или REJECTED и позволяют вручную возвращать их в очередь.

На 2026-11-04 локальный каталог содержит 67 записей источников: 3 ACTIVE, один включённый источник в ERROR, остальные требуют проверки, API или ручной настройки. Статусы относятся к локальной базе и могут меняться.

Поддерживаемые кодом каналы сбора:

- Ethereum Blog RSS;
- Ethereum Foundation Ecosystem Support RSS;
- GitHub Repository Search;
- DuckDuckGo Web Discovery — 12 поисковых запросов по ранним Web3-сигналам, включая публично индексируемые публикации X, Reddit и Telegram, сайты проектов, тестнеты, waitlists, гранты и раунды финансирования. Его наличие в коде не означает, что он ACTIVE в текущей базе.

RSS и GitHub проверяются по расписанию. Web Discovery использует публичную выдачу поисковой системы и имеет увеличенный интервал повторной проверки при временном HTTP 403. Это не автоматизация авторизованного браузерного аккаунта и не обход ограничений социальных платформ. Остальные зарегистрированные источники требуют отдельных разрешённых коннекторов, API или доступа; их состояние показано в разделе Sources. Не вставляйте секретные ключи в код или журнал.

Фоновый монитор сохраняет запуски, ошибки, новые исходные материалы и события. Один и тот же URL допускается как свидетельство от разных источников, но повторная ссылка внутри одного источника не дублируется. Автоматическое нечёткое объединение одноимённых сущностей пока не включено.

## Отбор, переводы и ограничения

Разделы **My Top Projects**, **Review Queue**, **Early Incubation**, **Waitlist**, **Watchlist** и **Deferred / Rejected** доступны в меню. Карточки верхнего списка появляются только после завершённого Level 2, статуса VERIFIED, оценки не ниже 60 и достоверности не ниже 60. На проверенном снимке базы 2026-11-04 верхний список пуст: недостаток подтверждений не заменяется высоким баллом.

### Видимость данных и интерфейс

На снимке базы 2026-11-04 было 386 досье, 668 связей с источниками, 67 записей источников (3 ACTIVE, 1 ERROR), 24 записи в очереди и 361 проект со статусом REJECTED. Исторические 291 проект / 26 карточек / 12 источников относятся к отчёту анализа от 2026-11-02, а не к текущим счётчикам базы. Отклонённые записи не удалены: они доступны в досье и архивном разделе. `/api/projects` поддерживает постраничную выдачу; клиент загружает страницы, чтобы не обрезать набор на лимите одной выборки.

Интерфейс использует локальный Inter Variable, графитово-синий фон, контрастные панели и лаймовый акцент. Поиск и фильтры применяются к загруженным реальным записям.

Русские описания текущей рабочей очереди сохранены в базе. Оригиналы не заменяются и доступны в досье. Новые описания можно перевести кнопкой в интерфейсе; перевод сохраняется для выбранной карточки. При отсутствии встроенного переводчика Chrome интерфейс предложит открыть Google Translate.

Счёт финансирования, команды и бесплатного участия начисляется только при наличии структурированных подтверждённых записей. UNKNOWN означает, что факт не удалось подтвердить, а не то, что факта нет. Оценка не обещает токен, аирдроп, грант или доход.

Никакие кошельки не подключаются, транзакции и регистрации не выполняются автоматически.

## Проверка

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe -m compileall -q app tools tests
```

Для каждого источника разделяйте наличие записи в каталоге и подтверждённую работу коннектора. `GET /api/sources` показывает статус каталога, последний запуск, а также отдельные `last_success_at` и `last_error_at`. Ошибки сохраняются без URL-параметров и тел ответов. Полный аудит зарегистрированных интеграций на 2026-11-04: [отчёт TASK 02](reports/2026-11-04-source-registry-and-integration-health.md). Свежая проверка внешних коннекторов может быть недоступна в среде без исходящего сетевого доступа; исторический успешный запуск не означает текущую доступность.

Базу можно экспортировать в JSON или CSV из интерфейса. Установить другой каталог данных можно через `BPI_DATA_DIR`.
